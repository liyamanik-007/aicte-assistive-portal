# Data Processing

Use this directory for scripts that extract and curate handbook content.

Suggested workflow:
1. Record the official source URL and handbook edition.
2. Extract text while preserving page numbers and section headings.
3. Manually inspect extracted passages against the source PDF.
4. Store curated requirements with source references.
5. Keep unverified or ambiguous items clearly marked.
6. Do not commit confidential data or large raw files unless the team has agreed to do so.
